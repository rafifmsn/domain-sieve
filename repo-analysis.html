Recommended four-tool reference stack and custom glue

To satisfy an institutional web-filtering mandate with minimal custom reinvention, combine the highest-leverage permissive or AGPL components from each category and focus engineering effort strictly on the thin glue layers between them.

Stage 1 · Discovery

Run certstream-server-go for ~300 certs/sec CT streaming alongside dnstwist and bbot (or amass) for mirror permutations and ASN/WHOIS pivoting. Add custom NRD zone-file ingestion.

Stage 2 · Collection

Deploy crawl4ai Docker browser pools for high-concurrency stealth Playwright rendering, Clean Markdown, DOM, and base64 PNG screenshots, or Lookyloo where full HAR forensic trees are required.

Stage 3 · Multi-Gate Funnel

Use IntelOwl for Gate A threat-feed dedup (URLhaus, OpenPhish, MISP), adapt PhishXGraph (XGBoost) + LightGBM/GLiClass for Gate B, and route escalations to an OpenAI-compatible abliterated VLM with strict JSON Schema.

Stage 4 · Evidence & Sync

Store immutable HTML, screenshots, redirect chains, and VLM logs in S3/MinIO + Postgres, route borderline scores (0.50 ≤ c < threshold) to an analyst queue (IntelOwl GUI), and build custom RPZ/BGP/SNI exporters.
